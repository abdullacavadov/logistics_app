# Açıq biznes qərarları (işə başlamazdan əvvəl)
1. Qiymət sahəsi məcburidirmi? Büdcə, yoxsa daşıyıcının yekun qiyməti (§5.1)?
2. Birbank təkrarlanan ödəniş, token, server bildirişi dəstəkləyirmi (§9.4)? Yoxsa hər ay əl ilə?
3. Güzəşt müddəti: var/yox, neçə gün (§9.7)?
4. SMS provayderi və xərc (§4.1)?
5. Hosting: PHP versiyası, Cron, SSH, queue worker (§14.3)?
6. Yük elanına müraciətdən sonra kritik sahələrin dəyişdirilməsi qaydası (§5.4)?
7. Eyni daşıyıcının eyni yükə rədd edildikdən sonra təkrar müraciəti (§8.2)? Hazırda: pending/accepted varsa 409.
8. Google Play / Apple Developer hesabları kimdə olacaq (§13.3)?
